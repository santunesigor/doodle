# Doodle themes

The same diagram in every theme. Pick one in `doodle.json` (`"theme": "chalk"`), with `--theme`, or for a single diagram with `@theme`. See [customize.md](../../skills/doodle/references/customize.md).

## `paper`

Warm paper, soft shadows, rounded font (the default).

<!-- doodle
flow: Can I deploy? (paper)
@theme paper
[a] Tests pass? | warn
[b] Deploy | it ships | ok
[c] Fix first | bad
a -> b: yes
a -> c: no
c -> a: try again
-->
